# 1️⃣ Telas de Autenticação  
Diretório utilizado:

```
/app/(auth)
```

Essas telas funcionam como uma pilha de pratos:  
- Login está na base  (denominado como @/app/(auth)/index.tsx
- Register entra por cima de Login caso o usuário não tenha uma conta e precise criá-la
- ResetPassword entra, também, por cima de Login, para caso o usuário tenha esquecido sua própria senha e precise redefini-la 

`router.back()` remove o “prato” atual.  
`router.push()` adiciona outro prato no topo. Nesse caso, a rota precisa ser passada como parâmentro, por exemplo: `router.push("/(auth)/register")`

---

## 1.2 Tela ResetPassword  

Essa tela deve ser simples:

- 1 campo: TextField (email)  
- 1 botão para solicitar redefinição  
- seta superior para `router.back()`  

Exemplo parcial:

```
<TextField
  label="E-mail"
  placeholder="Digite seu e-mail"
// ...
/>

```

E na tela Login:

```
<Text onPress={() => router.push("/(auth)/resetPassword")}>
  Esqueci minha senha
</Text>
```
